# 그리스이야기 (Greece Stories)

그리스 역사가 어렵게 느껴지는 어른을 위해, 한국어로 짧게 정리한 정적 사이트입니다. 영어 제목은 짧게 두고, 설명은 한국어로 씁니다.

나두 — 나의 모든 일상을 AI와 함께

자매 사이트 [나두신화](https://nadoo-myth.vercel.app)는 그리스·로마 신화를 다룹니다. [로마이야기](https://rome-stories.vercel.app)는 그 신화가 붙은 나라의 정치와 전쟁을 다룹니다. [이집트이야기](https://egypt-stories.vercel.app)는 같은 집안의 자매 사이트입니다. 그리스이야기는 폴리스와 전쟁, 평범한 하루를 다룹니다.

## 메뉴

- **홈** `/` — 다섯 시대, 모든 갈래, 자매 사이트
- **탄생·시대** `/origins` — 시 속의 영웅과 청동기 궁전, 미케네 → 초기 철기 → 고졸기 → 고전기 → 헬레니즘
- **지도** `/map` — 아테네, 스파르타, 코린토스, 테바이, 델포이, 델로스, 이오니아, 마케도니아, 시라쿠사, 알렉산드리아
- **폴리스** `/polis`, `/polis/[slug]` — 아테네, 스파르타와 길을 잡는 도시. `/cities`는 여기로 이어집니다
- **인물** `/people`, `/people/[slug]` — 솔론, 페리클레스, 레오니다스, 알렉산드로스 등. 소크라테스와 플라톤은 글의 종류를 구분해 적습니다
- **전쟁** `/wars`, `/wars/[slug]` — 페르시아 전쟁, 펠로폰네소스 전쟁, 알렉산드로스의 원정과 그 사이의 큰 싸움. 원인·상대·결과
- **일상** `/daily` — 아고라, 심포지온, 여성, 노예와 헤일로타이, 올림픽
- **군대** `/army` — 중장보병, 팔랑크스, 삼단노선
- **신과 전설 연결** `/myth-links` — 나두신화의 신·이야기·그리스 vs 로마로 이어지는 링크
- **관련 영화** `/movies` — 300, 트로이, 알렉산더, 아고라, 오디세이아 각색. 어디가 창작인지 구분. 불법 영상 링크 없음
- **출처** `/sources`

글의 꼴은 한 줄 요약, 핵심 세 가지, 펼치는 「조금만 더」입니다. 전설과 역사는 배지로 나눕니다.

## 개발

```bash
npm ci
npm run dev
npm run build
```

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript. 페이지는 빌드 때 정적으로 생성됩니다.

콘텐츠는 `data/`에 있습니다. `NEXT_PUBLIC_SITE_URL`의 기본값은 `https://greece-stories.vercel.app`입니다. 방문자 수는 Abacus 네임스페이스 `greece-stories`를 씁니다.

## 적는 기준

고대 기록의 이름과 위치만 밝히고, 없는 인용문을 만들지 않습니다. 현대 책의 문장을 번역해 붙이지 않습니다. 영화 제목은 실제 개봉·공개 제목을 쓰고, 작품을 볼 수 있는 불법 사이트는 안내하지 않습니다.
